## Files in this repository

Alongside this profile README are Spring Petclinic-related Maven/Gradle build files, wrappers, a Jenkinsfile, and local MySQL/PostgreSQL Compose services. Application source is absent, so this checkout is an incomplete scaffold and cannot be treated as a runnable Petclinic application. The Gradle configuration targets Java 17.

The database examples use demonstration credentials and are bound to localhost. Do not expose them publicly. Add the missing application source and review dependencies and database configuration before attempting a build or deployment.
